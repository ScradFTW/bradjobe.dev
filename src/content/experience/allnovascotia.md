allNovaScotia.com is a business-news outlet covering the province. The existing codebase was legacy PHP with no unit or end-to-end tests, so introducing both was one of the first things I did there. I built a **client-facing REST API** in front of that PHP back end, hosted on AWS, then developed and released the company's **React Native app** on top of it.

Later on I **migrated the legacy PHP site over to React and Next.js**, and helped integrate AWS [Elasticsearch](https://www.elastic.co) into the REST API.
